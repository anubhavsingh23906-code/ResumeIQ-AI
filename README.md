# ResumeIQ AI

AI-powered resume analysis and career guidance platform that analyzes resumes, identifies skills, matches candidates with target roles, highlights skill gaps, and provides career resources.

## 🚀 Live Demo

**[Try ResumeIQ AI](https://resumeiq-ai-drnn8kx5j5mxfueubani7c.streamlit.app/)**

## ✨ Features

* 📄 Resume PDF upload and text extraction
* 🧠 Automatic skill extraction
* 🎯 Role-based skill matching
* 🔍 Skill gap identification
* 💼 Career role analysis
* 📚 Curated learning resources
* 🗺️ Personalized career roadmap
* ⚡ Interactive Streamlit interface

## 🛠️ Tech Stack

* **Python**
* **Streamlit**
* **Pandas**
* **PDFPlumber**
* **Git & GitHub**

## 🔄 How It Works

```text
Resume Upload
      ↓
Text Extraction
      ↓
Skill Detection
      ↓
Target Role Selection
      ↓
Skill Matching
      ↓
Skill Gap Analysis
      ↓
Resources & Career Roadmap
```

## ▶️ Run Locally

```bash
git clone https://github.com/anubhavsingh23906-code/ResumeIQ-AI.git
cd ResumeIQ-AI

python -m venv venv
```

Activate the environment and install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

The application will open at:

```text
http://localhost:8501
```

## 🎯 Purpose

ResumeIQ AI is designed to help students and job seekers understand how their current skills align with their target career roles and identify areas they can improve.
